## What the plugin contributes

The website compiles 25 ordinary CSS stylesheets and 894 class owners through
the external `lightningcss-compact` Rust library. It renames 599 identities.
The adapter compiles explicit Rust, JavaScript, and Markdown bindings before
emission, keeping dynamic class operations as individual identity tokens.

**Naming-only and complete optimization produce identical stylesheet,
binding, and portable-manifest bytes on this website.** The complete search
evaluated 61 candidates and accepted zero declaration extractions, shared
classes, or identity elisions. Cascade conflicts and combined encoded costs
make the conservative representation preferable here. The standalone
synthetic evaluation demonstrates factoring on eligible fixtures; this
website does not establish an additional atom/bundle saving or a global
minimum for an application of this size.

## Coherence and availability

A cached document and its exact hashed CSS/JavaScript remain a coherent older
generation. Every managed document declares `eng-css-generation`; the router
checks it before loading or promoting another surface. Obsolete asset URLs
serve only their provenance-verified archived bytes, or return 404. A full-SHA
build check rejects collisions between current and archived short hash URLs.

The initial adoption preserves 60 exact prior-release asset bodies totaling
530,526 bytes. Native Chrome proves that the original cached feed boots those
assets and hard-navigates to a current destination before mixing generations.
Later releases must retain their generated assets across real browser
freshness, stale-document, and offline-cache horizons. The archive is not an
alias from an unknown old URL to current class-dependent bytes.

An unarchived missing initial asset now leaves semantic content and ordinary
links readable; it does not cause an automatic reload or silently acquire a
different class map. This preserves correctness with a deliberate availability
limit: the missing enhancement/style stays missing until ordinary navigation
or reload succeeds. Soft-navigation mismatch recovery remains bounded.
Private unsubscribe forms/results keep `no-store`, strict CSP, their current
URL/result, and a clean preferences link without replaying a POST. Real
disconnected service-worker reading retains a matching document and assets.

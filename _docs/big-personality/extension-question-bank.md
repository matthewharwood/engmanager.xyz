## Seventh lens: Personal Values

The **Twenty Item Values Inventory (TwIVI)** is an established brief measure of ten Schwartz personal values. The [official author page](https://gosling.psy.utexas.edu/two-short-measures-of-values-tivi-and-twivi/) permits anyone to use it for any purpose without asking permission. Cite [Sandy, Gosling, Schwartz, & Koelkebeck (2016)](https://doi.org/10.1080/00223891.2016.1231115). This permission applies to this instrument; it is not a blanket permission for other Schwartz questionnaires.

The JSON retains the exact official `sourceText`, including source punctuation, and he/she/they display variants. The author explicitly recommends preferred-pronoun branching. The table below uses singular they with only pronoun/verb-agreement changes; it does not rewrite portraits for a workplace context.

### Official administration

Here we briefly describe some people. Please read each description and think about how much each person is or is not like you. Using a 6-point scale from “not like me at all” to “very much like me,” choose how similar the person is to you.

**How much like you is this person?**

| Stored score | Response anchor |
| --- | --- |
| 1 | Not like me at all |
| 2 | Not like me |
| 3 | A little like me |
| 4 | Somewhat like me |
| 5 | Like me |
| 6 | Very much like me |

The original form presents anchors from 6 to 1. Preserve consistent labels and direction within this module. It uses six response options, unlike the five-option personality and interests modules.

### Exact scoring

There is no reverse scoring. Pair items 1+11 for Conformity, 2+12 for Tradition, and so on in table order. Each raw value is its two-item mean (1–6). The within-person priorities view uses `centeredPriority = pairMean - grandMean`, where `grandMean` is the mean of all 20 responses. Preserve integer pair sums and the total sum before display rounding.

Each centered score can range from −4.5 to +4.5; ten centered scores sum to zero. This is a mathematical constraint, not evidence that values are independent. A negative value means lower endorsement relative to this reader’s overall ratings, not absence of that value or moral inferiority. Flat answers produce all zero priorities and no leading value.

All 20 valid answers are required for a final values profile in this product. This conservative completeness rule avoids inventing a missing-data estimator. Users can skip the entire module. Missing responses remain null. Preserve ties; no population percentiles, moral ranking, job-fit score, or forced personality type.

**Precision limits:** each value has only two items. In the original evaluation, alpha estimates varied from .33 to .91; the two-week retest sample contained only 46 returning respondents. Report modest, tentative interpretations; avoid treating tiny differences as meaningful. Religion/custom items do not comprehensively capture secular cultural attachment, and the Security pair is not a workplace-security measure.

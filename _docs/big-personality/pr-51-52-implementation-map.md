## Research and external work, deliberately separate from the live v5 release

- The `pilot218`/`compact200`/`hybrid48` comparison and optional IPIP-IPC measure remain research candidates in `story-kit-v2/base/`. v5 offers the direct 48-item pilot as a separate optional chapter. Activating the compact form or a new interpersonal score requires validation and a new versioned questionnaire; it must not silently change the 170 scored items.
- Reliability, cultural fairness, and agreement with a commercial type test have not been established. Neither the code nor a report claims that public figures have verified type codes.
- Cloudflare has no configured domain in PR #51. v5 bundles images locally and gives the PDF kit same-origin HTTPS asset URLs. Moving them to a configured Cloudflare origin requires an approved domain, asset upload, CSP/release changes, and network verification. The current kit works without it.
- The 78 card fronts are named placeholders. PR #51 includes prompts and SVG source for future illustrated replacements. No card is represented as finished bespoke artwork.
- The app does not call an external LLM or generate the five-movement PDF automatically. The participant downloads and reviews a Markdown kit, then chooses a file-capable LLM. The web report and deterministic scores PDF remain available without that service.

## Privacy and evidence rules

All background and symbol approvals start off. Clearing an answer removes its approval. Exact birthday and unapproved demographics are excluded from the standard kit; story records do not alter trait, interest, value, color, or preference scores. A person's race, birthplace, culture, or symbol choices are self-reported context, never inputs to a claimed cultural-tightness score or employment decision. The external PDF prompt treats context and symbolic motifs as data, not instructions or diagnostic evidence.

If local storage cannot open, the preface keeps its optional inputs disabled and explains why; the scored assessment retains its existing session-only/backup path. This avoids implying that sensitive preface answers were saved when navigation would lose them.

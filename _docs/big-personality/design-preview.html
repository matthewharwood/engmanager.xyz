A few things to know

The full version will let you pause and resume. Some source statements discuss negative feelings and political attitudes. Any item can be skipped.

Skipped answers leave affected personality scales incomplete. The interest profile requires all 30 interest responses; the values profile requires all 20 values responses.

Your report will show response-scale scores. Population percentiles need appropriate reference data and are not included in v1.

Planned estimate: 25–35 minutes for all three modules. This estimate needs a pilot.

What do these scores mean?

Personality items are keyed using the instrument's scoring rules and averaged on a 1–5 scale. The area view shows counts of the 24 keyed scores for the selected trait; reverse-keyed items have already been transformed. It does not show original answer labels or how other people scored. Interests use separate 0–20 sums. Personal values use within-person priorities. None of these are population percentiles.

Why are facets useful?

Each broad personality domain contains six narrower facets. In the full product, these will be visible with completion information. A broad score can hide differences among facets; this preview does not invent facet estimates from domain means.
